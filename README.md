# DevOps Career Hub (বাংলা সংস্করণ) 🚀

**DevOps Career Hub** হলো DevOps ইঞ্জিনিয়ার এবং ক্লাউড প্র্যাকটিশনারদের জন্য একটি পূর্ণাঙ্গ, প্রোডাকশন-রেডি পার্সোনাল ক্যারিয়ার ও প্র্যাকটিস ম্যানেজমেন্ট প্ল্যাটফর্ম। এর মাধ্যমে চাকরির আবেদন ট্র্যাকিং, হ্যান্ডস-অন ল্যাব প্র্যাকটিস, লার্নিং রোডম্যাপ, টাস্ক ম্যানেজমেন্ট, ইন্টারভিউ প্রস্তুতি, ব্যক্তিগত নোট এবং সিভি ভল্ট এক ছাতার নিচে পর্যবেক্ষণ করা যায়।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **মাল্টি-ইউজার ডেটা আইসোলেশন ও সর্বোচ্চ নিরাপত্তা (Highest Priority)**:
   - প্রতিটি MongoDB ডকুমেন্ট অপরিবর্তনীয় `userId` (Firebase UID) দিয়ে সার্ভার লেভেলে সংরক্ষিত।
   - সার্ভার-সাইড ভেরিফিকেশন ছাড়া অন্য কোনো ব্যবহারকারীর তথ্য বা আপলোড করা ফাইল অ্যাক্সেস করা অসম্ভব।
   - HttpOnly, Secure, SameSite সেশন কুকি এবং Firebase Admin SDK ভিত্তিক নির্ভরযোগ্য যাচাইকরণ।

2. **জব অ্যাপ্লিকেশন ট্র্যাকার (Job Application Tracker)**:
   - টেবিল ভিউ ও কানবান বোর্ড ভিউ।
   - ফিল্টারিং (স্ট্যাটাস, কাজের পরিবেশ, চাকরির ধরণ, সোর্স), সার্চ এবং পেজিনেশন।
   - ডুপ্লিকেট কোম্পানি সতর্কবার্তা (নন-ব্লকিং)।
   - স্ট্যাটাস পরিবর্তনের টাইমলাইন ও হিস্ট্রি ট্র্যাকিং।
   - UTF-8 BOM এনকোডেড বাংলা সমর্থিত CSV এক্সপোর্ট।

3. **হ্যান্ডস-অন প্র্যাকটিস ট্র্যাকার (DevOps Practice Tracker)**:
   - Linux, Docker, Kubernetes, Terraform, CI/CD, AWS ইত্যাদি ক্যাটাগরি।
   - প্র্যাকটিস স্ট্রিক (Streak) ক্যালকুলেশন এবং গত ২৮ দিনের অ্যাক্টিভিটি হিটম্যাপ।
   - ব্যবহৃত কমান্ড, কোড স্নিপেট, সমস্যা এবং সমাধানের লগ।
   - "পুনরায় প্র্যাকটিস করুন" (Repeat Exercise) ফিচার।

4. **DevOps লার্নিং রোডম্যাপ (Learning Roadmap)**:
   - ১৪টি প্রি-বিল্ট কাস্টমাইজেবল রোডম্যাপ মাইলস্টোন (Linux থেকে প্রডাকশন প্রজেক্ট পর্যন্ত)।
   - কাস্টম মাইলস্টোন তৈরি ও অগ্রগতি (Progress %) স্লাইডার।
   - সামগ্রিক সমাপ্তি হার রিয়েল-টাইম ক্যালকুলেশন।

5. **টাস্ক ম্যানেজার ও শিডিউল ক্যালেন্ডার (Tasks & Calendar)**:
   - আজ, আসন্ন, ওভারডিউ এবং সম্পন্ন টাস্কের ভিউ।
   - ইন্টারভিউ এবং ডেডলাইন ক্যালেন্ডার গ্রিড (Asia/Dhaka টাইমজোন)।

6. **ইন্টারভিউ প্রস্তুতি (Interview Preparation)**:
   - টেকনিক্যাল প্রশ্ন ব্যাংক (প্রশ্ন-উত্তর লুকানো/দেখা সেলফ-টেস্টিং মোড)।
   - ইন্টারভিউ সেশন হিস্ট্রি এবং সেলফ-অ্যাসেসমেন্ট লগ।

7. **ডকুমেন্ট ও সিভি ভল্ট (Secure Cloudinary Vault)**:
   - সিভি, কভার লেটার ও সনদ ফাইল আপলোড।
   - ক্লাউডিনারি ইউজার-আইসোলেটেড ফোল্ডার স্টোরেজ ও নিরাপদ ডাউনলোড লিংক।

8. **অ্যানালিটিক্স ও ডাটা এক্সপোর্ট**:
   - Recharts দিয়ে সমৃদ্ধ চার্ট ও মেট্রিক্স।
   - সম্পূর্ণ পার্সোনাল ডাটা JSON ও CSV তে ডাউনলোড।

9. **সম্পূর্ণ বাংলায় Hind Siliguri ফন্ট ও ডার্ক/লাইট মোড**।

- **ফাইল স্টোরেজ**: Cloudinary API
- **ভ্যালিডেশন**: Zod, React Hook Form
- **চার্ট ও নোটিফিকেশন**: Recharts, Sonner

5. **Vercel অ্যাকাউন্ট** (প্রোডাকশন ডেপ্লয়মেন্টের জন্য)

## ⚙️ ধাপে ধাপে সেটআপ গাইডলাইন (Step-by-Step Guide)

### ১. ফায়ারবেস প্রজেক্ট তৈরি ও গুগল লগইন সক্রিয়করণ
1. [Firebase Console](https://console.firebase.google.com/) এ গিয়ে **Add project** এ ক্লিক করে একটি প্রজেক্ট তৈরি করুন।
2. বামদিকের মেনু থেকে **Build > Authentication** এ গিয়ে **Get Started** দিন।
3. **Sign-in method** ট্যাবে গিয়ে **Google** প্রোভাইডার সিলেক্ট করুন এবং **Enable** করে সেভ করুন।
4. **Authorized domains** সেকশনে আপনার লোকালহোস্ট (`localhost`) এবং Vercel ডেপ্লয়মেন্ট ডোমেন (যেমন `devops-career-hub.vercel.app`) যুক্ত করুন।
5. প্রজেক্টের গিয়ার আইকন (Project Settings) > **General** এ গিয়ে **Web app** (`</>`) তৈরি করুন এবং কনফিগারেশন ভ্যালুগুলো সংগ্রহ করুন:
   - `apiKey` (`NEXT_PUBLIC_FIREBASE_API_KEY`)
   - `authDomain` (`NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN`)
   - `projectId` (`NEXT_PUBLIC_FIREBASE_PROJECT_ID`)
   - `appId` (`NEXT_PUBLIC_FIREBASE_APP_ID`)

### ২. ফায়ারবেস অ্যাডমিন সার্ভিস অ্যাকাউন্ট কি তৈরি (Firebase Admin SDK)
1. Firebase Console > **Project Settings > Service accounts** ট্যাবে যান।
2. **Generate new private key** বাটনে ক্লিক করুন।
3. একটি JSON ফাইল ডাউনলোড হবে। সেখান থেকে সংগ্রহ করুন:
   - `project_id` (`FIREBASE_ADMIN_PROJECT_ID`)
   - `client_email` (`FIREBASE_ADMIN_CLIENT_EMAIL`)
   - `private_key` (`FIREBASE_ADMIN_PRIVATE_KEY`)

> **টিপস**: প্রাইভেট কি-তে থাকা নিউলাইনগুলোকে `.env.local` ফাইলে `\n` হিসেবে অথবা কোটেশন মার্কের ভেতরে রাখুন।

### ৩. মঙ্গোডিবি অ্যাটলাস ক্লাস্টার তৈরি ও নেটওয়ার্ক এক্সেস
1. [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) এ লগইন করুন।
2. একটি ফ্রি ক্লাস্টার (Shared M0) তৈরি করুন।
3. **Database Access** এ গিয়ে একটি নতুন ডাটাবেস ইউজার তৈরি করুন (Username & Strong Password)।
4. **Network Access** এ গিয়ে **Add IP Address** এ ক্লিক করে `0.0.0.0/0` (Allow Access from Anywhere) দিন যাতে Vercel সার্ভারলেস ফাংশন কানেক্ট হতে পারে।
5. **Database > Connect > Drivers (Node.js)** এ ক্লিক করে কানেকশন স্ট্রিং কপি করুন:
   - `mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0`

### ৪. ক্লাউডিনারি (Cloudinary) অ্যাকাউন্ট ও ক্রেডেনশিয়াল
1. [Cloudinary](https://cloudinary.com/) এ ফ্রি সাইনআপ করুন।
2. ড্যাশবোর্ড থেকে নিচের তিনটি তথ্য সংগ্রহ করুন:
   - **Cloud Name** (`CLOUDINARY_CLOUD_NAME`)
   - **API Key** (`CLOUDINARY_API_KEY`)
   - **API Secret** (`CLOUDINARY_API_SECRET`)

### ৫. লোকাল এনভায়রনমেন্ট ফাইল (.env.local) কনফিগারেশন
প্রজেক্ট রুটে `.env.local` নামে একটি ফাইল তৈরি করুন এবং `.env.example` অনুসরণ করে আপনার কিগুলো বসান:

```env
NEXT_PUBLIC_APP_URL=http://localhost:3000

NEXT_PUBLIC_FIREBASE_API_KEY=AIzaSy...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your-project
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your-project.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=123456789
NEXT_PUBLIC_FIREBASE_APP_ID=1:123456789:web:abcdef

FIREBASE_ADMIN_PROJECT_ID=your-project
FIREBASE_ADMIN_CLIENT_EMAIL=firebase-adminsdk-xxx@your-project.iam.gserviceaccount.com
FIREBASE_ADMIN_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIEvgIB...\n-----END PRIVATE KEY-----\n"

MONGODB_URI=mongodb+srv://devops_user:password@cluster0.xxx.mongodb.net/?retryWrites=true&w=majority
MONGODB_DB=devops_career_hub

CLOUDINARY_CLOUD_NAME=my_cloud
CLOUDINARY_API_KEY=123456789012345
CLOUDINARY_API_SECRET=abcdefghijklmnopqrstuvwxyz123

SESSION_SECRET=a_very_secure_random_key_of_at_least_32_characters
```

## 🏃‍♀️ প্রজেক্ট রান ও ডেভেলপমেন্ট (Running Locally)

### ১. ডিপেন্ডেন্সি ইনস্টলেশন:
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু:
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) এ প্রবেশ করুন।

### ৩. টাইপচেক ও লিন্টিং:
```bash
npm run lint
```

### ৪. প্রোডাকশন বিল্ড যাচাই:
```bash
npm run build
```

### ৫. মাল্টি-ইউজার ডেটা আইসোলেশন টেস্ট রান:
```bash
npm run test:isolation
```

## 🚢 Vercel এ ডেপ্লয়মেন্ট নির্দেশিকা (Deploying to Vercel)

1. প্রজেক্টের কোড আপনার GitHub রিপোজিটরিতে পুশ করুন:
   ```bash
   git add .
   git commit -m "feat: complete DevOps Career Hub in Bengali"
   git push origin main
   ```
2. [Vercel Dashboard](https://vercel.com/) এ গিয়ে **Add New... > Project** সিলেক্ট করুন।
3. আপনার গিটহাব রিপোজিটরিটি ইমপোর্ট করুন।
4. **Environment Variables** সেকশনে গিয়ে `.env.local` এর সকল ভ্যারিয়েবল (Firebase, MongoDB, Cloudinary, Session Secret) হুবহু যুক্ত করুন।
5. **Deploy** বাটনে ক্লিক করুন।
6. ডেপ্লয় সম্পন্ন হওয়ার পর ফায়ারবেস কনসোলের **Authentication > Settings > Authorized domains** এ গিয়ে আপনার Vercel ডোমেনটি (যেমন `your-app.vercel.app`) যুক্ত করে দিন।

## 🔍 সাধারণ সমস্যা সমাধান (Troubleshooting)

| সমস্যা | কারণ | সমাধান |
|---|---|---|
| **Google Sign-In Popup Closed / Unauthorized Domain** | Firebase Authorized Domains এ ডোমেন যুক্ত নেই | Firebase Console > Authentication > Settings > Authorized Domains এ `localhost` বা Vercel ডোমেন যুক্ত করুন। |
| **Firebase Admin: invalid private key** | প্রাইভেট কি-তে থাকা নিউলাইন ফরম্যাট ভুল | `.env` ফাইলে কি-টি ডাবল কোটেশনে রাখুন এবং `\n` সঠিকভাবে অক্ষুণ্ন রাখুন। আমাদের কোডে স্বয়ংক্রিয়ভাবে `.replace(/\\n/g, '\n')` হ্যান্ডেল করা আছে। |
| **MongoDB connection timeout / IP whitelist** | মঙ্গোডিবির নেটওয়ার্ক এক্সেস বন্ধ | MongoDB Atlas এ গিয়ে Network Access > IP Access List এ `0.0.0.0/0` এলাউ করুন। |
| **Cloudinary 401 Unauthorized** | ভুল Cloud Name বা API Secret | Cloudinary ড্যাশবোর্ড থেকে ক্রেডেনশিয়াল পুনরায় চেক করে আপডেট করুন। |
